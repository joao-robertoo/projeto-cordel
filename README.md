<h2>👋 Sobre o Projeto</h2>

Este site apresenta de forma simples e visual a beleza da Literatura de Cordel, destacando sua origem, história, características e importância para a cultura brasileira.

O objetivo deste projeto foi criar uma página informativa, leve e responsiva, reforçando minhas habilidades com HTML, CSS e construção de layouts limpos e organizados.
<br>
<br>

<h2>🎨 Conteúdo do Projeto</h2>

Explicação clara sobre o que é a Literatura de Cordel

Breve histórico e sua relação com a cultura popular

Características dos folhetos de cordel: versos rimados, xilogravuras, linguagem popular

Seções organizadas e de fácil leitura

Layout visual agradável e intuitivo
<br>
<br>

<h2>🧰 Tecnologias Utilizadas</h2>

HTML5 — Estrutura semântica organizada

CSS3 — Estilização simples, moderna e responsiva

Google Fonts — Tipografia mais bonita e legível

Layout responsivo — A página se adapta bem em celular, tablet e desktop
<br>
<br>

<h2>📱 Responsividade</h2>

O site foi criado pensando em acessibilidade e experiência do usuário, oferecendo boa leitura em:

💻 Computadores

📱 Celulares

📟 Tablets
<br>
<br>

<h2>🎯 Objetivo do Projeto</h2>

Com este projeto, pude praticar:

Construção de páginas informativas

Organização de conteúdo textual

Responsividade com CSS

Design limpo e centrado no conteúdo

Além disso, é uma forma de valorizar um pedaço importante da cultura brasileira.
<br>
<br>

<h2>👋 About the Project</h2>

This website presents, in a simple and visual way, the beauty of Cordel Literature, highlighting its origin, history, characteristics, and importance in Brazilian culture.

The goal of this project was to build a clean, lightweight, and responsive informational page, while practicing HTML, CSS, and visual layout organization.
<br>
<br>

<h2>🎨 Project Content</h2>

Clear explanation of what Cordel Literature is

Short historical overview and cultural context

Main characteristics: rhymed verses, woodcut-style illustrations, popular storytelling

Organized sections for smooth reading

Simple and intuitive visual design
<br>
<br>

<h2>🧰 Technologies Used</h2>

HTML5 — Structured and semantic markup

CSS3 — Clean and responsive styling

Google Fonts — Modern and readable typography

Responsive layout — Optimized for mobile, tablet, and desktop
<br>
<br>

📟 Tablets

<h2>🎯 Project Goal</h2>

With this project, I practiced:

Building informational pages

Clean design focused on content
